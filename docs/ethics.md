# Ética e uso responsável

Este repositório demonstra um **pipeline de ML de portfólio**. Ele:

1. **Não** é um dispositivo médico (SaMD) nem ferramenta clínica.
2. **Não** substitui avaliação de profissionais de saúde.
3. Usa um dataset público clássico, com limitações conhecidas de tamanho e representatividade.

Qualquer demonstração (dashboard, CLI, métricas) deve ser apresentada com esse contexto.
